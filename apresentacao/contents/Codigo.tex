\begin{frame}{Detalhamento do Código}
\begin{itemize}[<+->]
    \item A função \texttt{filter\_team\_sports} agrupa os dados para identificar os esportes de equipe.
    \item Funções auxiliares, como \texttt{create\_directory}, garantem a estruturação dos diretórios para os resultados.
    \item Cada nó do grafo recebe atributos adicionais (armazenados em formato JSON) que enriquecem a análise.
    \item A criação de arestas é realizada comparando os resultados dos pódios em cada evento, onde a hierarquia das medalhas determina o peso inicial da conexão. A presença de múltiplas interações incrementa o peso, refletindo a intensidade da relação competitiva.
\end{itemize}
\end{frame}
