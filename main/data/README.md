# Dados

Este diretório contém o dataset olímpico.

## Dataset Principal

**Arquivo**: `athlete_events.csv` (36 MB)
**Fonte**: "120 years of Olympic history: athletes and results" (Kaggle)
**Período**: Atenas 1896 até Rio 2016
**Registros**: 271.117 atletas
**Colunas**: 18 (ID, Name, Sex, Age, Height, Weight, Team, NOC, Games, Year, Season, City, Sport, Event, Medal)

## Nota

Este arquivo não é commitado no Git devido ao tamanho (36 MB).

Para executar o projeto, você precisa:
1. Baixar o dataset do Kaggle
2. Colocar o arquivo `athlete_events.csv` neste diretório
3. Executar o pipeline de análise

Link: https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results
