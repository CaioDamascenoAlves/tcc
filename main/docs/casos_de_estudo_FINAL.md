## INSIGHTS PRELIMINARES

### Padrões Observados

1. **Gap de Gênero Histórico:**
   - Todos os eventos femininos começaram depois
   - Gap varia de 16 anos (natação) a 108 anos (boxe)
   - Média: 53 anos de diferença

2. **Iconic Score:**
   - Masculino: 0.951 (quase máximo)
   - Feminino: 0.480 (metade)
   - Reflexo direto do gap histórico

3. **Fragmentação:**
   - Eventos mais antigos = mais fragmentados
   - Eventos femininos tendem a ser MENOS fragmentados (menos componentes)
   - Possível razão: menos edições = gerações mais próximas

4. **Crescimento Recente:**
   - Futebol feminino: +78% audiência
   - Basquete feminino: +43% audiência
   - Tendência de aumento de popularidade
